# Defect Record: D-0004

- **ID:** D-0004
- **Title:** Preview Verifier Silent Pass on NaN or Corrupted Telemetry Metrics
- **Severity:** High
- **Category:** Reliability / Verification Bypass
- **Component:** `apps/worker/src/verifier.ts` (PreviewVerifier)
- **Found-By:** Campaign 9 (Performance & endurance adversary)
- **Steps to Reproduce:**
  1. Telemetry input provided with `visualDiffRatio: NaN` or negative LCP.
  2. `evaluateVerification` compares `NaN > 0.01` which returns `false`.
- **Expected:** Telemetry with `NaN` or invalid metric bounds should fail verification and trigger safety rollback.
- **Actual:** Evaluates as `passed: true`.
- **Evidence:** `apps/worker/test/repro-d0004.test.ts`
- **Failing Test Path:** `apps/worker/test/repro-d0004.test.ts`
- **Root Cause:** Missing sanity validation for `Number.isNaN()` or negative values on incoming telemetry metrics.
- **Fix Commit:** `69a08c1` (verifier.ts telemetry sanity pre-flight check)
- **Regression Test:** `apps/worker/test/repro-d0004.test.ts`
