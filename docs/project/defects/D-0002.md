# Defect Record: D-0002

- **ID:** D-0002
- **Title:** File Manager Trailing Dot and Alternate Data Stream Bypass in Sensitive File Blacklist
- **Severity:** High
- **Category:** Security / Path Traversal
- **Component:** `connectors/wordpress/src/FileManager/JailGuard.php`
- **Found-By:** Campaign 4 (File manager security pass)
- **Steps to Reproduce:**
  1. Call `jailGuard->resolveSecurePath('themes/wp-config.php.')` or `themes/wp-config.php::$DATA`.
  2. The blacklist checks `$lower === 'wp-config.php'`.
- **Expected:** Trailing dots, spaces, and NTFS stream specifiers (`::$DATA`) should be stripped before blacklist comparison.
- **Actual:** Filename check fails to match, allowing blacklisted names with trailing characters to bypass the check.
- **Evidence:** `connectors/wordpress/tests/FileManagerTest.php`
- **Failing Test Path:** `connectors/wordpress/tests/ReproD0002Test.php`
- **Root Cause:** Lack of normalization for trailing dots, spaces, and NTFS alternate data streams in `JailGuard::assertNotSensitive`.
- **Fix Commit:** `69a08c1` (JailGuard.php trailing dot and stream normalization)
- **Regression Test:** `connectors/wordpress/tests/ReproD0002Test.php`
- **Status:** Verified
