# Defect Record: D-0001

- **ID:** D-0001
- **Title:** XSS Vulnerability in Gutenberg Compiler via Unsanitized Text and Javascript URI Schemes
- **Severity:** High
- **Category:** Security / Injection
- **Component:** `@mimic-manager/ir` (GutenbergCompiler)
- **Found-By:** Campaign 4 (Security offensive pass on IR Replicator)
- **Steps to Reproduce:**
  1. Construct an `IRDocument` with a heading containing raw HTML markup: `<script>alert(1)</script>`.
  2. Construct a button node with an attribute `href: "javascript:alert(1)"`.
  3. Compile the document via `compiler.compile(doc)`.
  4. Inspect the generated Gutenberg block markup.
- **Expected:** Text content should be HTML-entity encoded (`&lt;script&gt;`), and dangerous URI schemes (`javascript:`, `vbscript:`, `data:`) must be sanitized or neutralized to `#`.
- **Actual:** Raw scripts and dangerous schemes were directly emitted into Gutenberg block comments and markup.
- **Evidence:** `packages/ir/test/repro-d0001.test.ts`
- **Failing Test Path:** `packages/ir/test/repro-d0001.test.ts`
- **Root Cause:** Absence of HTML entity escaping and protocol allowlisting in `packages/ir/src/gutenberg.ts`.
- **Fix Commit:** `69a08c1` (packages/ir/src/gutenberg.ts escapeHtml & sanitizeUri)
- **Regression Test:** `packages/ir/test/repro-d0001.test.ts`
- **Status:** Verified
