# Defect Record: D-0003

- **ID:** D-0003
- **Title:** Speed FixEngine Overrides Images with Inline Style Dimensions
- **Severity:** Medium
- **Category:** Functionality / Layout Distortion
- **Component:** `connectors/wordpress/src/Speed/FixEngine.php`
- **Found-By:** Campaign 7 (Speed-fix verification adversary)
- **Steps to Reproduce:**
  1. Pass HTML containing `<img src="logo.png" style="width: 240px; height: 60px;">`.
  2. Enable `FIX-PERF-002` (Missing Image Dimensions).
  3. `FixEngine::optimizeHtml()` runs.
- **Expected:** If the image tag already has inline CSS `width:` and `height:` defined, it should not inject default `width="800" height="600"`.
- **Actual:** Injects `width="800" height="600"` because it only checks for HTML attributes `width=` and `height=`.
- **Evidence:** `connectors/wordpress/tests/ReproD0003Test.php`
- **Failing Test Path:** `connectors/wordpress/tests/ReproD0003Test.php`
- **Root Cause:** Incomplete attribute checking in `applyMissingImageDimensions`.
- **Fix Commit:** `69a08c1` (FixEngine.php inline style dimension check)
- **Regression Test:** `connectors/wordpress/tests/ReproD0003Test.php`
- **Status:** Verified
