== Description ==

Free and Secure platform for image optimization, PageSpeed and SEO fixes, UI section replication, and visual file management, with a WordPress connector and a PWA command center.
Created by SK Sahinur Islam. A Wefik project.

== External Services ==

This plugin communicates with your self-hosted Mimic Manager backend API using mutual HMAC-SHA256 authentication for media optimization, PageSpeed audits, and UI section replication.
Zero third-party telemetry. 100% data sovereignty.
